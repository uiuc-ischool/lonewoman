# Document Groups Page: Organization and Reprint Network Maps

The Document Groups page (`/groups/`) shows how individual newspaper articles about Juana Maria are organized into **document groups** — clusters of one original article and the reprints derived from it. Each group is displayed as a collapsible entry with a list of reprints and an animated map that shows the geographic spread of the text across time.

**URL:** `/groups/`  
**Page file:** `pages/document-groups.md`

---

## What is a Document Group?

A document group is a set of articles that share the same source text. Every group has exactly one **original** publication and zero or more **reprints**. Reprints are typed by how faithfully they reproduce the original:

| Reprint type | Meaning |
|---|---|
| `original` | First known publication of this version of the article |
| `direct` | Near-verbatim copy of the original |
| `truncated` | Shortened version |
| `paraphrase` | Substantially rewritten |

All articles in a group share the same `group_reprint_id` value in the metadata (e.g. `Goliah1853_DPT_reprint`). An article can belong to more than one group if its text became the source for multiple independent reprint chains (see `metadata_notebooks/article_document_group_analysis.ipynb` for the many-to-many analysis).

## Data Sources

| File | Role |
|---|---|
| `_data/cb_complete_metadata_images_tropes_reprints_transcripts.csv` | Master metadata — drives the page layout (group listings, article titles, publication info) |
| `_data/article_map_locations.csv` | One row per article, with geocoded coordinates — drives the reprint network maps |

### `article_map_locations.csv` columns used by the maps

| Column | Description |
|---|---|
| `article_id` | Unique article identifier |
| `publication` | Newspaper/magazine name |
| `date` | Publication date (`YYYY-MM-DD`, or bare year) |
| `publisher_location` | Plain-text location of publication |
| `lat` / `lng` | Geocoded coordinates of the publication location (destination of the arc) |
| `origin_location` | Source location of the text (where the original was published) |
| `origin_lat` / `origin_lng` | Geocoded coordinates of the origin — arc source point |
| `reprint_type` | `original`, `direct`, `truncated`, or `paraphrase` |
| `group_reprint_id` | Which document group this row belongs to |

The CSV has 494 rows (vs. 481 unique articles) because 13 articles appear in more than one document group. It was generated by `metadata_notebooks/prepare_article_map_locations.py`, which geocodes locations via Nominatim and caches results to avoid re-querying.

## Page Structure (`pages/document-groups.md`)

**Front matter:**
```yaml
layout: page
use_reprint_maps: true
```

The `use_reprint_maps: true` flag tells `_layouts/default.html` to inject the CDN scripts for MapLibre GL and deck.gl, plus `assets/js/reprint-map.js`, into the page `<head>`.

**Liquid logic:**
1. Filters master metadata to `display_template == "compound_object"` rows only (one per article; image child rows excluded)
2. Filters further to rows where `reprint_type contains "original"` → these are the group anchors
3. Sorts originals by `date` and groups them under year headings (`<h2 id="year-YYYY">`)
4. For each original, collects all articles sharing the same `group_reprint_id` → the full group
5. Renders each group as a `<details class="map-group">` element with:
   - A `<summary>` showing the original article title (linked to its item page) and reprint count
   - Original's publication, location, year, and author
   - A `<ul>` of reprints with colored type badges, linked to item pages
   - `{% include reprint-map.html group_id=orig.group_reprint_id %}` — the map for this group

## Reprint Network Maps

Each group gets its own animated map showing the arc of text movement from origin to publication location, revealed when the group is expanded.

### Data baking: `_includes/reprint-map.html`

At Jekyll build time, this include filters `_data/article_map_locations.csv` to the rows matching the current `group_id` and bakes the data into an inline `<script>` block:

```js
window._reprintMapRegistry = window._reprintMapRegistry || {};
window._reprintMapRegistry['map-goliah1853-dpt-reprint'] = [
  { article_id: "...", publication: "...", date: "...",
    lat: 42.65, lng: -73.75, origin_lat: 37.79, origin_lng: -122.41,
    reprint_type: "truncated", ... },
  ...
];
```

Each group's data is keyed by a slugified container ID so multiple maps can coexist on the same page without clashing.

### Lazy initialization: `assets/js/reprint-map.js`

Maps are **not rendered until the user opens a group** — this avoids initializing dozens of WebGL contexts at once on page load.

A `DOMContentLoaded` listener watches all `<details class="map-group">` elements. When one is toggled open for the first time:
1. It reads the group's data from `window._reprintMapRegistry`
2. Calls `new ReprintMap(containerId, data, { autoplay: true })`
3. Stores the live instance in `window._reprintMapInstances` for later pause/resume

When a group is collapsed, any running animation is paused.

### `ReprintMap` class

The `ReprintMap` constructor (defined in `reprint-map.js`) builds a self-contained animated visualization inside the container `<div>`:

**Basemap:** MapLibre GL 3.6.2 with a dark CartoDB tile style  
**Overlays:** deck.gl 8.9.35 — two layers per render frame:
- `ArcLayer` — draws arcs from `[origin_lng, origin_lat]` to `[lng, lat]` for non-original rows. Arc color matches reprint type. Arcs use `greatCircle: true` so long-distance routes follow geodesic paths.
- `ScatterplotLayer` — draws a dot at each article's publication location. Originals get a slightly larger dot.

**Color coding:**

| Type | Color |
|---|---|
| Original | Gray `#d1d5db` |
| Direct | Blue `#3b82f6` |
| Truncated | Orange `#f97316` |
| Paraphrase | Green `#22c55e` |

**Animation:** Articles appear in chronological order. A `currentTs` variable advances from `MIN_TS` to `MAX_TS` in `BASE_FRAMES = 140` ticks (at speed 1×). Each tick, only rows with `d.ts ≤ currentTs` are rendered, so the reprint network grows over time.

**Controls bar** (at the bottom of each map):
- Play / Pause button
- Reset button
- Current-date label and time scrubber (seek anywhere in the timeline)
- Speed slider (0.2× to 4×)

**Co-located splay:** When multiple articles share the same lat/lng (e.g. two reprints published in the same city), they are spread into a small circle so dots don't overlap. The circle radius is `SPLAY_PX = 12` pixels, recalculated on zoom changes to stay pixel-stable.

**Edge case guards in the code:**
- No geocoded rows → shows a "No location data available" message instead of a blank map
- All articles at one location → skips arcs (ScatterplotLayer only), centers map on that point
- All articles share the same date → hides the controls bar; all points appear at once
- Missing origin coordinates → falls back to destination coords as arc source

### CDN dependencies (loaded by `_layouts/default.html`)

Only loaded when `page.use_reprint_maps: true`:
- MapLibre GL 3.6.2 CSS + JS — `unpkg.com/maplibre-gl@3.6.2`
- deck.gl 8.9.35 — `unpkg.com/deck.gl@8.9.35`
- `assets/js/reprint-map.js` — local file defining `ReprintMap`

## Files NOT Used by This Page

`_layouts/map.html` and `_includes/js/map-js.html` are **not part of the document groups system**. They are stock CollectionBuilder files that power a separate Leaflet-based map of all collection items (used by other CB pages if configured). They are included in the repo as part of the CollectionBuilder template but are not connected to the document groups or reprint arc visualizations.
