## Collection Metadata

The table below lists one row per article, with publication-level metadata (title, publication, author, date, location, tropes). This is a simplified view: the site itself is organized around `objectid`, a more granular identifier that tracks each article's membership in image groups (the scanned pages that make up a single article) and reprint groups (the network of original and reprinted articles an article belongs to) — which is why some articles appear more than once behind the scenes, once per reprint group they're part of.

The table below provides sorting and basic search of the collection contents. Use the "CSV" button below to download the filtered metadata you see on the page.

Clicking "Download Data" at the top right offers three complete downloads instead of just what's visible on screen:
- **Complete Metadata** — the full master spreadsheet exactly as it drives the site, with one row per article per document group plus one row per scanned page image
- **Article Metadata** — a simplified, one-row-per-article spreadsheet matching the table below
- **Metadata Facets** — unique value counts for publication, author, and format, useful for understanding the collection at a glance
